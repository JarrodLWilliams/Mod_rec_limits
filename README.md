[![Actions Status][actions-badge]][actions-link]
[![PyPI version][pypi-version]][pypi-link]
[![PyPI platforms][pypi-platforms]][pypi-link]

Exploration of the fundamental limits of modulation recognition.

## Installation

```bash
python -m pip install mod_rec_limits
```

From source:
```bash
git clone https://github.com/JarrodLWilliams/Mod_rec_limits
cd Mod_rec_limits
python -m pip install .
```
